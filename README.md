# Muneeb Ahmed | Video Editor Portfolio

Static portfolio site. One file (`index.html`), no build step.

## Put it on GitHub
1. Go to github.com/new, name it `portfolio`, click Create repository.
2. Click "uploading an existing file".
3. Drag in `index.html`, `vercel.json` and `README.md` (the files, not the folder).
4. Click Commit changes.

## Deploy on Vercel
1. Go to vercel.com/new and sign in with GitHub.
2. Import the `portfolio` repository.
3. Framework Preset: Other. Leave build settings empty. Click Deploy.

Every future change you commit to GitHub redeploys automatically.
